## Unresolved Risks & Platform Caveats
1. **Headless vs Native Plasma Environment:**
   - Headless offscreen Qt test execution (`QT_QPA_PLATFORM=offscreen`) validates application logic, signals, and widget lifecycle, but does not certify native Wayland compositor windowing under KDE Plasma, GPU acceleration hardware backends, or sub-millisecond frame rendering.
2. **PyInstaller Binary Rebuild Overhead:**
   - Running the packaging smoke test (`tests/test_packaging.py::test_pyinstaller_build_and_execution`) triggers a full PyInstaller binary compilation taking ~30 seconds. Setup scripts intentionally isolate packaging tests so standard unit runs remain fast.
3. **Model Weights Checksum Validation:**
   - Real ONNX model downloads in test suites are mocked using SHA-256 fixture standard signatures to ensure 100% offline test execution without external network dependence.
