## Technical Architectural Changes & Key Bug Fixes

### 1. SHARED SETTINGS CONTRACT v1 & Settings Hardening (`settings_manager.py`)
- Defined `SettingsPersistenceError(Exception)` raised strictly on atomic write failure.
- Implemented `snapshot() -> dict[str, Any]` returning a thread-safe `copy.deepcopy` under `self._lock`.
- Implemented `apply_changes(changes: dict[str, dict[str, Any]]) -> None` validating/committing section changes atomically. In-memory state is published **only after** persistence to disk succeeds.
- Updated `get(section, key)` to return deep copies of mutable objects (dicts/lists) to prevent thread/caller state pollution outside lock.
- Added strict type checking for hotkeys:
  - Custom key bindings must be single characters (`len(key) == 1`).
  - Rejects empty, multi-character, duplicate, or invalid key strings.
- Differentiated files vs. directories in folder path validation (`os.path.isfile(path)` rejected for folder fields).
- Preserved unknown root keys and unknown section fields during validation and repair.

### 2. User Isolation & Directory Writability Verification (`paths.py`)
- Enhanced `_ensure_dir_or_fallback` to test actual directory writability using `.write_test_<pid>_<tmp>` temporary file creation/deletion.
- Updated temporary directory fallbacks from shared `/tmp/ImageSorter` to user-isolated paths: `/tmp/imagesorter-<uid>/<category>`.

### 3. Tooltip Bug Fix & Settings Dialog Validation (`ui_settings.py`)
- **Tooltip Bug Fix**: Fixed `save_settings` to read `chk_tooltips.isChecked()` and store it as `ui.tooltips_enabled` (previously ignored).
- **All-or-Nothing Commit**: Rewrote `save_settings` to perform all input, file-vs-directory, and hotkey validations prior to invoking `settings.apply_changes(changes)`. On validation failure or `SettingsPersistenceError`, reports critical error dialog without closing the window or leaving partial writes.
- **Asynchronous Model Verification**: Added `ModelCheckWorker(QThread)` to check model/labels SHA256 integrity off the GUI thread without freezing the settings dialog. Status updates honestly to `"Checking..."`, `"Download Model"`, or `"Model Ready"`.
- **Managed Download Lifecycle & Cancellation**:
  - Connected `QProgressDialog.canceled` signal to `cancel_download()`.
  - Implemented `cancel_download()` calling `downloader.requestInterruption()`.
  - Handled user cancellation explicitly in `on_download_finished()` without claiming download success.
  - Added `closeEvent()` override ensuring running worker and downloader threads are safely interrupted and waited on before dialog destruction.

## Integration Contract & Proposed Reserved Keys for P02

To prevent hotkey collision between global/navigation action shortcuts and custom category folder assignment hotkeys, task P03 defines the following custom hotkey validation rules:
- Custom folder bindings **must be single-character keys** (e.g., `'1'`, `'2'`, `'A'`).
- Duplicate key bindings in the hotkey configuration table are rejected.
- **Proposed Reserved Key List for P02 Handoff**:
  - `Space`, `RightArrow` (Next Image)
  - `LeftArrow`, `Backspace` (Previous Image)
  - `Delete` (Trash / Delete Image)
  - `Ctrl+Z` (Undo Action)
  - `Ctrl+S` (Save Settings / Manual Action)
  - Fallback Direct Navigation Keys: `Z`, `L`, `C`, `S`, `R` (When Level 0/1/2 evaluation passes).
