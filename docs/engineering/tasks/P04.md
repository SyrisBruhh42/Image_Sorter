## Technical Accomplishments & Contract Realignment

### 1. Shared AI Contract v1
- **API Version & Signature Exposing:**
  - Set `AITagger.API_VERSION = 1`.
  - Extended constructor: `AITagger.__init__(self, model_dir: str | None = None, *, hardware_acceleration: bool = True) -> None`.
  - Extended inference method: `AITagger.get_tags(self, image_path: str, top_k: int = 3, *, threshold: float = 0.5) -> list[str]`.
  - Updated `BaseVisionEngine.get_tags` abstract method signature to require keyword-only `threshold=0.5`.
- **Import Isolation:**
  - Removed global `multiprocessing.set_start_method("spawn", force=True)` execution during module import.

### 2. Pinned Preprocessing Pipeline
- Aligned preprocessing strictly with the pinned HuggingFace specification (`mobilenet_v2_1.0_224-ONNX` revision `f7f884d9505b4c69f8a260d9967ff7791bafa498`):
  1. `PIL.ImageOps.exif_transpose` orientation normalization.
  2. Shortest-edge resize to 256 using bilinear interpolation (`Image.Resampling.BILINEAR`).
  3. Center crop of 224x224.
  4. Rescale pixels to `[0.0, 1.0]` (`/ 255.0`).
  5. Channel mean/std normalization with mean `[0.5, 0.5, 0.5]` and std `[0.5, 0.5, 0.5]` (maps solid white `[255, 255, 255]` to `[1.0, 1.0, 1.0]`).
  6. Returns float32 contiguous NCHW tensor `[1, 3, 224, 224]`.

### 3. Inference Mapping, Bounds & Filtering
- Explicitly handles 1,001 output logits by stripping background class at index 0 (mapping indices 1..1000 to the 1,000 ImageNet labels).
- Cleanses non-finite values (`NaN`, `+inf`, `-inf`) before and after softmax.
- Bounds `top_k` strictly to `[1, len(labels)]`.
- Filters top tags using configurable `threshold` (default `0.5`).

### 4. Hardware Provider Prioritization
- Refined `get_prioritized_providers()` in `hardware_scan.py` to ensure known accelerated providers (TensorRT, CUDA, ROCm, MIGraphX, OpenVINO, DirectML, CoreML) rank ahead of `CPUExecutionProvider`, while any unexpected runtime providers (e.g., `AzureExecutionProvider`) rank after `CPUExecutionProvider`.
- Honored `hardware_acceleration=False` in `AITagger.__init__` to force `['CPUExecutionProvider']`.

### 5. Interruption Handling & Zero-Trust Downloading
- `ModelDownloader` checks `self.isInterruptionRequested()` in `run()` and streaming chunk loops in `_download_file_secure`.
- Canceling or network failures preserve existing valid model/label artifacts and clean up temporary `.tmp` download files.
