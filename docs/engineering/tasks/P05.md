## 2. Architecture & SHARED DECODER CONTRACT v1

### 2.1 Shared Decoding Engine (`src/imagesorter/image_decoding.py`)
- **EXIF Orientation Auto-Transform**: Utilizes `QImageReader` with `setAutoTransform(True)`. Rotations and flips (e.g., orientation 6 rotating 90° CW) are automatically applied during decoding.
- **Pre-allocation Memory Bounds**: Inspects `reader.size()` before decoding and calculates estimated uncompressed memory (`width * height * 4`). Requests exceeding `max_allocation_bytes` (default 500 MB) are rejected prior to buffer allocation to defend against image decompression bombs or out-of-memory crashes.
- **Bounded Preview Downscaling**: Supports `target_size=(width, height)`. Downscales previews preserving aspect ratio via `Qt.AspectRatioMode.KeepAspectRatio` and `Qt.TransformationMode.SmoothTransformation`.
- **Embedded Color Profiles**: Converts valid non-sRGB embedded color profiles (e.g. Display P3, Adobe RGB) to sRGB using `QColorSpace(QColorSpace.NamedColorSpace.SRgb)`.
- **Explicit Diagnostic Errors**: Confines decoding exceptions per request and returns descriptive diagnostic messages for non-existent files, zero-byte empty files, corrupt headers, oversized dimensions, and unsupported RAW/container extensions (`.heic`, `.cr2`, `.nef`, `.arw`, `.dng`, etc.).

### 2.2 Image Loader Thread (`src/imagesorter/image_loader.py`)
- **SHARED DECODER CONTRACT v1 API**:
  ```python
  loader.add_task(
      filepath: str,
      *,
      request_id: str | None = None,
      generation: int = 0,
      target_size: tuple[int, int] | None = None,
      priority: int = 0,
  ) -> str
  ```
  - `priority=0`: Foreground current image (processed before preloads).
  - `priority > 0`: Lower-priority preloads.
  - Returns explicit string `request_id`.
- **Signal Specification**:
  - `image_ready = pyqtSignal(dict)` emitting:
    ```python
    {
        "request_id": str,
        "generation": int,
        "filepath": str,
        "image": QImage | None,
        "error": str | None,
    }
    ```
  - `image_loaded = pyqtSignal(str, QImage)` preserved for backward compatibility with legacy callers.
- **Task Scheduling & Coalescing**:
  - Priority queue (`priority`, `seq_num`).
  - Coalesces duplicate requests for identical `(filepath, target_size, generation)`.
- **Bounded Backlog**: Caps pending preload queue at `MAX_QUEUE_CAPACITY = 50`. Automatically drops worst low-priority preloads when capacity is reached (never drops `priority=0` requests).
- **Generation Tracking & Invalidation**: `clear_tasks(new_generation=...)` flushes obsolete tasks and updates generation identity. Obsolete/cancelled tasks are discarded without heavy decoding.
- **Nonblocking Shutdown**: `request_stop()` signals thread loop exit asynchronously and emits standard `QThread.finished`. `stop()` preserves synchronous waiting for legacy tests.
- **Thread Safety**: Strictly decodes into `QImage`. No `QPixmap` or GUI widgets are created in the background thread.

   ```python
   def on_image_ready_v1(self, result: dict) -> None:
       req_id = result["request_id"]
       gen = result["generation"]
       filepath = result["filepath"]
       qimg = result["image"]
       error = result["error"]

       if gen < self.current_generation:
           return  # Ignore stale result from previous directory/generation

       if qimg is not None:
           # Convert QImage to QPixmap on GUI thread!
           pixmap = QPixmap.fromImage(qimg)
           self.update_image_display(filepath, pixmap)
       elif error:
           logger.warning(f"Image decode error for {filepath}: {error}")
   ```
3. **Queue Requests with Priority & Target Size**:
   ```python
   # Current image (priority 0)
   self.loader.add_task(
       current_path,
       generation=self.current_generation,
       target_size=(view_width, view_height),
       priority=0,
   )

   # Preload next image (priority 1)
   self.loader.add_task(
       next_path,
       generation=self.current_generation,
       target_size=(view_width, view_height),
       priority=1,
   )
   ```
4. **Directory Navigation**:
   ```python
   self.current_generation += 1
   self.loader.clear_tasks(new_generation=self.current_generation)
   ```
5. **Shutdown**:
