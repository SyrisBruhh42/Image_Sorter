## Summary of Accomplishments & Architectural Decisions

### 1. SHARED LAUNCH CONTRACT v1 & Launch Requests Helper
* Created `src/imagesorter/launch_requests.py` providing `parse_launch_paths(args: Sequence[str]) -> list[str]`.
* Positional arguments (files or folders) are expanded deterministically (sorted alphabetically for directories), validated against supported image extensions (`.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`, `.gif`, `.tiff`, `.tif`), resolved to absolute canonical paths, and deduplicated while preserving input order.
* Implemented `open_paths(paths: list[str]) -> None` on `MainViewer` and monkeypatched `MainViewer.__init__` to support optional `initial_paths` while preserving 1-argument compatibility.
* Explicitly defined transient launch behavior: initial launch paths act as a transient view; triggering reload (`R` key) or closing settings restores the standard persisted source directory.

### 2. Desktop Entry & Window Icon Wiring
* In `src/imagesorter/main.py`, wired `app.setDesktopFileName("imagesorter")` to align with `imagesorter.desktop` as required by KDE Plasma and GNOME desktop shell integration.
* Added window icon loading on `QApplication` using `get_resource_dir() / "imagesorter.png"`.

### 3. Linux AppImage Build Interface & Freedesktop Cleanup
* Added `python build.py --appimage` support to `build.py`.
* On Linux x86_64, `build.py --appimage` fetches a checksum-verified `appimagetool` binary (SHA-256 `b90f4a8b18967545fda78a445b27680a1642f1ef9488ced28b65398f2be7add2`), constructs `dist/ImageSorter.AppDir`, and outputs `dist/ImageSorter-x86_64.AppImage`.
* Updated `build_appimage.sh` to generate proper `AppRun` scripts with `0o755` execution permissions.
* Removed unsupported `.isp` MIME registration from Freedesktop artifacts.
